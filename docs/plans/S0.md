```

```
Empty folders hold `.gitkeep`. `tests/Privacy` gets a placeholder `PrivacySuiteTest` that asserts the suite runs. Real cases start in S3 (SLICES).

**Pest architecture tests** (`tests/Architecture`, group `NFR-021`), written first and proven red with a temporary violating class (recorded in progress.md), then green:
1. `App\Modules\*\Http\Controllers` do not use `Illuminate\Database\Eloquent\*`, `App\Modules\*\Models`, `App\Modules\*\Queries`, or the `DB` facade.
2. Module isolation (dataset over the 10 modules): module A never uses module B's `Models`, `Queries`, `Policies`, `Http`; it may use B's `Actions`, `DTOs`, `Events`, `Enums`.
3. `Actions` have suffix `Action`, are `final`, and do not use `Illuminate\Http\*Response`, `Symfony\…\Response` or `response()`.
4. `DTOs` are `readonly` with suffix `Data`. `Http\Requests` extend `FormRequest` with suffix `Request`.
5. `Http\Resources` extend `JsonResource` and match `^(Citizen|Operations|Field|Admin|Public)[A-Z]\w*Resource$` (audience prefixes from the path scopes; `Public` is for the unauthenticated `/report-types`, `/settings/public`; **assumption, please confirm**).
6. `DB` facade only in `Actions`, `Queries`, `App\Support`, migrations, seeders.

Order (FK-safe):

3. `roles`, `permissions`, `role_permissions` (composite PK).
4. `field_units` (before `users`, since `users.field_unit_id` → `field_units.id`).
5. `users`, `refresh_tokens`.
6. `report_types` (unique `(category, name)`).
7. `reports`, `report_timeline`, `report_attachments`.
8. `ai_extractions` (`report_id` unique, nullable).
9. `chat_messages`.
10. `assignments` + **raw SQL** `CREATE UNIQUE INDEX assignments_one_active_per_report ON assignments (report_id) WHERE mission_status <> 'cancelled';`.

13. Framework tables per B2 (`cache`, `cache_locks`, `jobs`, `job_batches`, `failed_jobs`) from Laravel's stock migrations.

Type mapping (Blueprint where it maps 1:1, raw SQL otherwise):

| DBML | Migration |
|---|---|
| `int [pk, increment]` | `$table->increments()` (serial) |
| `bigint [pk, increment]` | `$table->bigIncrements()` |
| `uuid [pk, default: gen_random_uuid()]` | `$table->uuid('id')->primary()->default(DB::raw('gen_random_uuid()'))` |
| `varchar(n)` / `text` / `boolean` / `numeric(6,2)` / `jsonb` / `inet` | `string(n)` / `text` / `boolean` / `decimal(6,2)` / `jsonb` / `ipAddress` |
| `timestamptz` (+ `default now()`) | `timestampTz()` (`->useCurrent()`), with `not null` exactly as in the DBML |
| `geography(Point,4326)` | `$table->geography('location', subtype: 'point', srid: 4326)` |
| native ENUM column | `DB::statement('ALTER TABLE … ADD COLUMN status report_status NOT NULL DEFAULT \'received\'')` inside the same migration (Blueprint `enum()` would create a varchar + CHECK, which is not native) |
| FKs | `foreignId/foreignUuid(...)->constrained()` with **no** `ON DELETE` action (DBML specifies none, so PostgreSQL defaults to NO ACTION) |
| indexes | exactly the DBML `indexes {}` blocks; no extras (B7) |

Assumptions to confirm: `users.updated_at`, `reports.updated_at` are nullable without default, exactly as in the DBML (Eloquent fills them). `users.password_hash` keeps its DBML name (S1 maps `getAuthPassword()`).

# Slice plan (Approved)

Each slice: backend first (migrations → actions → endpoints → FR/NFR tests → contract + privacy checks), then web/mobile screens against Prism, then wiring to real endpoints. Every slice ends with DoD (root CLAUDE.md §7) and a `docs/progress.md` update. Each slice gets its own `docs/plans/<slice>.md` approved before coding.
